FOTO DOKUMENTASI ASLI WAKANGKA
===============================
Website menggunakan foto sumber dari Wakangka melalui URL eksternal.
Jika memiliki screenshot atau foto dari Wakangka yang IZINNYA sudah diperoleh,
letakkan file JPG di folder ini dengan nama berikut (foto lokal otomatis diprioritaskan):

puncak-wakangka.jpg
lembah-wakangka.jpg
alam-wakangka.jpg
pertanian-wakangka.jpg
wisata-wakangka.jpg
masyarakat-wakangka.jpg
galeri-alam.jpg
galeri-kemah.jpg
galeri-kegiatan.jpg
galeri-panen.jpg
galeri-puncak.jpg

Untuk penggunaan di situs publik, pastikan izin/ketentuan hak cipta dari pemilik foto.
Jika file JPG tidak ada, website mencoba memuat foto dokumentasi dari sumber asli.
Jika sumber memblokir pemuatan gambar, tersedia fallback desain, tidak foto AI.
